Graphify Jamoa Protokoli

Har kim o'z kompyuterida o'z bazasini ko'taradi. Bilim esa fayl bo'lib yuradi — baza emas. Shu bitta qoida hamma narsani soddalashtiradi.

Graphify nima

Claude Code uchun doimiy xotira. Suhbat yopilsa ham qarorlar, promptlar va hujjatlar qoladi — keyingi safar Claude o'nlab faylni qaytadan o'qimasdan, bir so'rov bilan kerakligini topadi.

Qidiruv ma'no bo'yicha ishlaydi: aniq so'zni bilish shart emas. Va butunlay lokal — vektorlar shu kompyuterda hisoblanadi, hech qanday API chaqirilmaydi.

O'rnatish

Uch qadam, taxminan besh daqiqa. Python 3.10+ bo'lishi kerak.

  1. Repozitoriyani oling

    git clone https://github.com/Ibrohim-Bxone/graphify-mcp.git
cd graphify-mcp

  2. O'rnatuvchini ishga tushiring

    install.bat

    U virtual muhit yaratadi, kutubxonalarni qo'yadi va Graphify'ni Claude Code'ga MCP server sifatida ro'yxatga oladi. Birinchi marta bir necha daqiqa oladi.

  3. Claude Code'ni yopib qayta oching

    MCP serverlari ishga tushganda bir marta o'qiladi — qayta ochmaguningizcha Graphify ko'rinmaydi.

Asosiy tushuncha

Bu qismni tushunsangiz, qolgani o'z-o'zidan aniq bo'ladi.

Ko'chadi — ulashiladi
  • .md fayllar — qaydlar, qo'llanmalar, promptlar
  • Bot arxivi — har fayl ichida to'liq yozuv JSON blok sifatida
  • Papka, git repo, hatto Telegramdagi fayl

Matn — haqiqat manbai. U yengil, o'qiladi va har kimning bazasida qayta qurilaveradi.

Ko'chmaydi — shaxsiy
  • kg_db/ — vektor baza
  • token_stats.json, models_config.json
  • Sizning sessiya xotiralaringiz

Baza — hosila indeks, nusxa ko'chirish uchun emas. U repoda ham .gitignore ichida.

Ya'ni: siz fayl ulashasiz, sherigingiz uni o'z bazasiga indekslaydi. Hech kim hech kimning shaxsiy xotirasini ko'rmaydi.

Ulashish — bitta buyruq

Jamoadan kelgan .md fayllarni o'z bazangizga qo'shish: 

# graphify-mcp papkasi ichida turib:
.venv\Scripts\python.exe indexer.py "C:\jamoa-bilim" --project shared --kind doc

--project shared — eng muhim qism. Shu yorliq bilan yozilgan hamma narsa qaysi loyihada ishlayotganingizdan qat'i nazar qidiruvda chiqadi. Boshqa yorliq bersangiz, u faqat o'sha loyihada ko'rinadi.

Buyruqni qayta ishga tushirsangiz dublikat bo'lmaydi — fayl yo'li bo'yicha yangilanadi. Ya'ni papka o'zgargan sari shunchaki qaytadan yugurtirasiz.

Bot arxivi tayyor to'plam

Botimiz yig'gan 377 ta markdown fayl aynan shu formatda — har birining oxirida to'liq yozuv JSON blok sifatida turadi. O'sha papkani olib, yuqoridagi buyruq bilan indekslasangiz, jamoaning bir necha oylik topilmalari sizning bazangizda paydo bo'ladi.

Ulashishdan oldin bir marta o'qib chiqing

Fayl ketgach qaytmaydi. Shaxsiy qaydlar, mijoz ma'lumotlari, kalitlar va parollar tasodifan qaydlar orasiga tushib qolgan bo'lishi mumkin. Ulashish papkasini alohida saqlang — hamma narsani emas, ataylab tanlanganini.

Tez-tez so'raladigan

Bazani to'g'ridan-to'g'ri nusxa qilib bersam bo'ladimi?

Texnik jihatdan mumkin, lekin qilmang. kg_db/ ichida sizning shaxsiy sessiya xotiralaringiz ham bor, va u ~22 MB ikkilik fayl — nima ketayotganini ko'rib bo'lmaydi.

Markdown ulashish esa ko'rinadigan, tanlanadigan va qayta quriladigan. Shu sababli protokol shunday.

Embedding modelini almashtirsam nima bo'ladi?

Bitta kolleksiyada ikki xil model aralashmaydi. Model almashtirsangiz kg_db/ ni tozalab, fayllarni qaytadan indekslash kerak — markdown saqlanib turgani uchun bu arzon amal.

Bir xil faylni ikki marta indekslasam dublikat bo'ladimi?

Yo'q. Yozuvlar fayl yo'li va bo'lak raqami bo'yicha kalitlanadi, shuning uchun qayta ishga tushirish yangilash bo'lib chiqadi.

Internet kerakmi?

Faqat o'rnatishda (kutubxonalar yuklab olinadi). Undan keyin qidiruv ham, saqlash ham offline ishlaydi.

Graphify ko'rinmayapti, nima qilay?

Deyarli har doim sabab bitta: Claude Code qayta ochilmagan. MCP serveri faqat ishga tushganda o'qiladi.

Kod yangilangandan keyin ham xuddi shunday — git pull qilgach Claude Code'ni yoping va qayta oching.
